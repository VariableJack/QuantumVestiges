# GamerParadise
A custom portal to various utilities and calculators for various games, along with personally developed games

## How to run the servers
Currently, the only way to run the front end or back end is via the CLI.

### Installation
Install Node.js, v18
Install NPM

### Backend
Open a CLI window and go to the `GamerParadise/backend` folder, then run `node app.js`

### Front end
Open a new CLI window and go to  the `GamerParadise/frontend` folder, then run `npm start`
